🔎 导入同名变量做「可视化套对」
导入一份 .xlsx / .csv / .txt（首行为英文变量名表头，与本系统 key 一致）。系统会按顺序（或按 ID/编号）把每行数据填进对应记录的空位并以紫色标注，方便在核对窗与原件逐项比对。仅填空位，不覆盖已识别值（可勾「覆盖」）。

多家免费视觉大模型可选（智谱 GLM-4.6V · 硅基 Qwen3-VL · OpenRouter · GitHub GPT-4o · NVIDIA · Gemini + 自定义）。点右上角 ⚙ 选服务、填自己的 API Key、测试连接。Key 只存在本机浏览器，不经任何中转。
